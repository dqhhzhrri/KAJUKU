## 🛠️ Panduan Singkat Buat Kamu yang Mau Ikut Kontribusi / Edit Website

Mau nambahin fitur baru, benerin *bug*, atau sekadar update konten kegiatan KAJUKU? Gampang banget kok! Ikuti langkah-langkah seru di bawah ini ya:👇

### 1️⃣ Siapin Senjata Tempurmu (Persiapan)

* Buka teks editor kesayanganmu (Rekomendasi banget pakai **VS Code** biar makin asyik coding-nya 😎).
* Pastikan komputermu sudah terinstal **Node.js** dan **Git**.

### 2️⃣ Kloning Repositori (`git clone`) 📥

Buka terminal di teks editor atau komputer kamu, lalu jalankan perintah ini untuk mendownload/mengambil kodenya langsung dari *remote repository*:

```bash
git clone https://github.com/dqhhzhrri/KAJUKU.git

```

### 3️⃣ Masuk ke Direktori Proyek 📂

Pindahkan posisi terminalmu ke folder hasil clone tadi dengan mengetik:

```bash
cd KAJUKU

```

### 4️⃣ Instal Kebutuhan Proyek (Dependencies) 📦

Install semua modul dan *packages* yang dibutuhkan aplikasi dengan menjalankan:

```bash
npm install
# atau kalau kamu pake yarn/pnpm/bun:
yarn install
# atau
pnpm install

```

### 5️⃣ Jalankan Server Lokal (Development Mode) 🚀

Yuk, intip hasil kodingannya secara *real-time* di browser dengan mengetik perintah ini:

```bash
npm run dev

```

Buka browser kesayanganmu dan akses 👉 **[http://localhost:3000](http://localhost:3000)**. Selamat, website-nya sudah jalan di komputermu! 🎉

### 6️⃣ Mulai Mengedit & Ngoding 🎨✨

Buka folder proyek ini di VS Code, lalu kamu bisa mulai mengedit file-file utamanya (misalnya di dalam folder `app/` jika menggunakan struktur Next.js App Router). Perubahan yang kamu buat bakal otomatis ter-update (*live-reload*), lho!

### 7️⃣ Simpan & Kirim Perubahan (Push/Pull Request) 🔄

Udah selesai ngedit dan mau kontribusimu masuk ke *branch* utama repo ini? Ikuti alur Git standar berikut:

1. Cek status perubahan:
```bash
git status

```


2. Tambahkan file yang sudah diedit:
```bash
git add .

```


3. Berikan pesan komit yang jelas:
```bash
git commit -m "fitur: update halaman beranda / deskripsi kegiatan"

```


4. Tarik dulu *update* terbaru dari *branch* utama biar gak konflik (opsional tapi disarankan):
```bash
git pull origin main

```


5. Kirim (Push) hasil kerjamu ke repo:
```bash
git push origin main

```


*(Atau buat Pull Request baru jika kamu bekerja di branch terpisah).*
